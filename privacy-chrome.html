剪拼 ClipStitch 隐私政策

适用平台：Google Chrome · 最后更新：2026年10月8日

剪拼在您的设备本地处理视频截图、字幕与相关设置，用于截图、字幕画面拼接、裁剪、复制和下载。扩展不向开发者或第三方服务器上传这些素材，没有广告追踪或使用情况统计服务。

1. 适用范围

本政策说明 Google Chrome 版剪拼 ClipStitch 如何访问、使用、保存与处理信息。您观看的视频网站、浏览器、扩展商店、邮箱服务和本政策的网页托管服务分别适用其自身的隐私规则。

2. 扩展在本地处理哪些信息

  • 视频与网页内容：所选视频画面、可读取的字幕文字及位置、视频或页面标题。用于截取画面、判断字幕变化、拼接和编辑图片，以及生成文件名。网页截图路径会临时截取当前可见标签页的内容，再在本地裁剪出视频范围。
  • 页面与播放状态：采集期间的当前页面地址、视频来源、播放或暂停状态、播放时间及字幕状态。用于确认当前播放器、判断视频是否已切换、及时结束采集。页面地址与视频来源保留在页面运行内存中，不作为浏览历史上传或保存到素材数据库；扩展不调用浏览历史接口。
  • 相关操作与设置：与播放器按钮、暂停操作及快捷键有关的鼠标和键盘信号，以及按钮显示、图片格式和明暗主题设置。用于响应操作和保存偏好，不用于广告或用户行为分析。
  • 采集元数据：本轮采集的标签页和框架标识、标题、时间、截图顺序、裁剪边界、字幕及失败诊断。部分失败诊断含字幕文本，与本轮素材一同保存在本地。

扩展不要求注册插件账号，不提供付费或广告服务，不读取系统剪贴板。复制功能会根据您的操作把图片写入剪贴板；下载功能会把图片或截图 ZIP 保存到浏览器下载目录。

3. 信息的用途与共享

上述信息仅用于实现您操作的视频截图、字幕画面拼接、编辑和导出功能。扩展不出售这些信息，不用作广告、信用评估或贷款决策，不将其传送给开发者或第三方服务器，也没有云端素材同步服务。

复制、下载或将图片粘贴到其他应用后，由您决定如何使用或分享导出的内容；接收内容的应用或服务可能另行处理这些信息。

剪拼对用户数据的使用遵守 Chrome Web Store User Data Policy，包括其 Limited Use 要求。

4. 保存位置与保存时间

最近一轮截图和采集元数据保存在扩展本地的 IndexedDB 中，以便您停止采集或重新打开侧栏后继续编辑。成功开始新一轮采集时，旧截图会被清除，旧会话会被替换。没有按天数自动清理素材的功能。

设置单独保存在浏览器的扩展本地存储中。截图、元数据和设置没有开发者服务器副本。扩展未提供自定义密码加密或云端备份；请使用您设备和浏览器提供的访问保护。

5. 您如何访问、调整与删除信息

  • 通过侧栏查看、裁剪、复制或下载最近一轮素材，并可删除单张或批量截图。
  • 删除截图会删除所选图片，但本轮标题、状态和部分诊断等会话元数据可能仍保留。开始新采集前，请先导出需要保留的图片。
  • 通过设置调整格式、按钮和主题偏好；可停止采集、禁用扩展或卸载扩展来停止后续处理。
  • 当前没有“一键清除全部数据”按钮。需要彻底清除扩展本地数据时，可在 Google Chrome 扩展管理页卸载剪拼。

卸载或删除扩展中的素材不会删除已经下载的文件，或您复制、粘贴到其他应用中的内容。这些内容需要您在相应位置另行删除。

6. 权限与安全

扩展使用网页访问权限发现播放器、显示按钮、读取可用字幕及截取当前可见标签页；使用本地存储保存设置与素材；使用侧栏展示和编辑结果；使用下载和剪贴板写入权限导出图片。后台图像处理页面和运行代码随扩展包提供，不从远程服务器加载并执行脚本。

截图可能包含视频或网页中显示的个人信息。请在采集、复制、下载和对外分享前确认画面范围，以及您愿意保留的内容。

7. 主动联系开发者与本政策网页

若您通过邮件主动联系开发者，您的邮件地址、正文和自行提供的附件会由邮箱服务处理，并用于回复该支持或隐私请求。请只提供处理问题所需的信息；如需删除您主动提供的信息，可通过同一邮箱联系开发者。邮箱服务自身的记录和备份适用该服务的规则。

本政策网页不添加分析统计脚本。网页托管平台可能为安全和运行需要处理访问日志，例如访问者 IP 地址。若本页由 GitHub Pages 托管，GitHub 会记录访问者 IP 地址用于安全目的，具体见 GitHub 隐私声明。访问政策网页不等于扩展向该平台上传截图或字幕。

功能或数据处理方式变化时，我们会更新本政策及页面上的更新日期。您可以通过本页面查看最新说明。
